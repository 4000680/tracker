Подключить Google Таблицу

Разовая настройка с компьютера. После неё записи из карточек будут автоматически попадать в одну таблицу на вашем Диске.

  1. Откройте таблицу «Лаборатории — Грани».
  2. В меню таблицы выберите Расширения → Apps Script.
  3. Удалите только пример myFunction в новом проекте. Скопируйте весь код ниже и вставьте вместо примера. Сохраните проект под именем «Грани — синхронизация лабораторий».
  4. Вверху выберите функцию setupLabsSync, нажмите Выполнить и разрешите этому проекту изменять вашу таблицу. После выполнения в журнале появится КОД ПОДКЛЮЧЕНИЯ. Сохраните его для шага 6. Код даёт доступ к записи в эту таблицу — вводите его только в настройках трекера.
  5. Нажмите Начать развёртывание → Новое развёртывание (названия могут немного отличаться). Тип — Веб-приложение. «Выполнять от имени» — Я. «У кого есть доступ» — Все. Нажмите «Развернуть» и скопируйте URL веб-приложения, заканчивающийся на /exec. Саму Google Таблицу публиковать или открывать для всех не нужно.
  6. В своём Telegram-боте откройте трекер → «Лаборатории» → Подключить Google. Вставьте URL и код из шага 4. Нажмите Проверить и подключить.

Трекер отправит уже внесённые записи и будет отправлять новые после сохранения. При сбое запись останется в Telegram, а приложение покажет, что Google ещё не обновлён. Можно повторить отправку кнопкой «Синхронизировать». Редактируйте рабочие данные в карточках: обратной загрузки изменений из Google нет.

Загружаем код…

Если интерфейс Google выглядит иначе, остановитесь на этом шаге и пришлите скриншот без кода подключения. Подтверждать подключение можно только после успешной проверки в трекере.
